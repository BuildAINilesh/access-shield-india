# AccessibleNow India — sales playbook

**Principle:** Free scan discovers pain. Monetize discovery → remediation → evidence → governance.

## Funnel

1. **Free scan** (`/scan`) — acquisition only (issue summary).
2. **Developer SaaS** (₹1,499/mo · ₹14,990/yr) — detailed findings + limited AI fixes.
3. **Expert services** — documented audit, AT testing, remediation, SEBI pack (project “from” prices).
4. **Professional SaaS** (₹7,999/mo · ₹79,990/yr) — teams, widget, reports, journeys.
5. **Enterprise programme** (from ₹2.5L/yr) — monitoring + evidence + training + CSM.

## Bank / BFSI mapping

| Customer need | SKU |
|---------------|-----|
| Know what’s broken | Free scan → Developer |
| Documented audit for board / SEBI | `audit-web` + `sebi-pack` |
| Screen reader / keyboard evidence | `at-manual` + Red journeys (Pro+) |
| Fix owners & deadlines | Remediation SKU + Issues tracker |
| Prove progress over time | Professional/Enterprise monitoring + posture |
| Governance / RPwD / GIGW packs | Enterprise evidence packs + Learn |
